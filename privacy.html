Política de privacidade

Última atualização: 30 de outubro de 2026.

O Chronos é um calendário que mostra e altera os teus eventos do Google Calendar. É um projeto pessoal e de código aberto, gerido por Miguel Silva.

Dados a que o Chronos acede

  • O endereço de email da tua conta Google, para identificar a conta.
  • A lista dos teus calendários.
  • Os eventos dos teus calendários, para os mostrar, criar, alterar, mover e apagar a teu pedido.

Onde ficam os dados

Os eventos são pedidos diretamente pelo teu browser ao Google e não passam por nenhum servidor do Chronos. Não são guardados pelo Chronos.

No teu browser ficam guardados o teu email, a lista de calendários, as tuas preferências e uma chave de sessão cifrada.

Um pequeno serviço do Chronos no Cloudflare Workers renova o acesso ao Google. Recebe essa chave de sessão apenas para pedir um novo acesso e não guarda nenhum dado.

Partilha de dados

O Chronos não vende, não partilha e não usa os teus dados para publicidade. Não usa ferramentas de análise nem cookies de rastreio.

Para carregar a app, o teu browser liga-se ao GitHub Pages, ao Cloudflare e ao Google, incluindo o Google Fonts. Estes serviços recebem dados técnicos normais, como o endereço IP.

Google API Services

O uso e a transferência de informação recebida das APIs Google cumprem a Google API Services User Data Policy, incluindo os requisitos de Limited Use.

Remover os teus dados

Usa Remover na lista de contas. O Chronos cancela o acesso e apaga os dados dessa conta deste browser. Também podes cancelar o acesso em myaccount.google.com/permissions.

Contacto

Para questões de privacidade, abre um pedido em github.com/miguelsiilva1/Chronos/issues.
